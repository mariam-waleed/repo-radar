2. Functional Test Execution

TC-01 - Verify Debounced GitHub Repository Search ✅ Passed

Requirement: FR-01

Steps

  1. Clear the browser Network log.
  2. Quickly type react without intentionally pausing.
  3. Observe the Network tab while typing.
  4. Stop typing and wait for the search results.

Expected Result

  • A GitHub search request is not sent for every keystroke.
  • The application waits briefly after typing stops before sending the request.
  • Results correspond to the final query.

TC-02 - Verify Stale Search Results Are Not Displayed ✅ Passed

Requirement: FR-01

Steps

  1. Enable a slow network profile such as Slow 3G.
  2. Search for react.
  3. Before completion, replace it with redux.
  4. Observe the final results.

Expected Result

  • Old results do not overwrite the newer query.
  • Only the current query results remain visible.

TC-03 - Verify Search Pagination ✅ Passed

Requirement: ENH-01

  1. Search for react.
  2. Verify up to 10 results on the first page.
  3. Navigate to page 2 and verify the results change.
  4. Return to page 1.
  5. Verify Previous/Next control states.

Expected Result

  • Pagination loads the corresponding result page.
  • Previous is disabled on page 1.
  • Next is disabled on the last available page.

TC-04 - Verify Pagination Resets for a New Search ✅ Passed

Requirement: ENH-01

  1. Search for react.
  2. Navigate past page 1.
  3. Replace the query with redux.

Expected Result

  • Pagination resets to page 1.
  • Results belong to the new query.
